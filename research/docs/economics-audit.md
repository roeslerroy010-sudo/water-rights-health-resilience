## 1. F1 —— 默认情景下没有稀缺，因此没有经济学

对 66 节点 LP 求解并读取对偶变量：

| 情景 | availability | 水量平衡约束对偶值非零的节点数 | 影子价格范围 |
|---|---|---|---|
| historical | 1.00 | **0 / 66** | — |
| **ssp245（默认）** | 0.86 | **0 / 66** | — |
| dry | 0.82 | 66 / 66 | > 0 |
| ssp585 | 0.70 | 66 / 66 | 0.0926 – 1.2960 元/m³ |

对偶值为 0 = 该节点再多给一立方米水，目标函数不增加 = **水的稀缺租金为零**。

由此可以精确解释三个此前被当作"现象"记录的事实：

1. **默认情景成交量 = 0 m³**。不是数据问题，也不是"外部调水太充裕"这种定性说法——
   是因为稀缺租金处处为零，**交易的收益为零**，市场无事可做。
2. **健康底线（26%）滑块在配置上完全无效**。四档情景下城市供水覆盖率恒为 100%，
   底线约束从未收紧过。
3. **健康税没有在"再配置"任何水**。工业配水占需求比恒为 **0.888**，恰好等于
   `1 − ε·τ·loss = 1 − 0.90×0.24×0.52`。也就是说工业取水量完全由需求上限公式的
   算术决定，LP 没有参与。

> **含义**：我们把机制演示放在了一个机制无法运作的世界里。真正有经济内容的是
> **干旱 / SSP5-8.5 情景**——那里影子价格转正、出现约 3.98 亿 m³ 真实换手。
> 这和视频叙事线 *"a drought year in Wuhan"* 恰好一致。**默认情景应该改成干旱年。**

## 2. F2 —— 影子价格就是市场价，我们已经算出来却扔掉了

在水量平衡约束上的对偶变量 λᵢ，量纲是元/m³，经济含义就是**节点 i 的水权市场出清价**。
这是资源配置 LP 的标准结果（Enke–Samuelson–Takayama 空间均衡框架），也是智利 Limarí、
澳洲 Murray–Darling、中国水权交易所定价的同一套逻辑。

**已验证**：`glpk.solve()` 返回的 `result.dual` 包含全部 198 个约束的对偶值，
其中 66 个是节点水量平衡。这是免费的、现成的。

当前代码没用它，而是显示：

```
P_market = 0.35 + scarcity×0.9 + τ×0.04 + tradingCost×0.5
```

默认参数下这条公式给出 **0.4096 元/m³**，而同一次求解的真实影子价格是 **0**。
**我们在为一件边际稀缺租金为零的商品报价 0.41 元。** 水资源经济学背景的评委
（导师张驰、桌面评审）会立刻看出这一点。

改用对偶值还额外带来三样现在没有的东西：

- **空间价差**。66 个节点各有各的价，而不是全流域一个数。价差就是交易的收益来源。
- **交易的经济判据**。当且仅当 `λ_买 − λ_卖 > 单位交易成本` 时交易发生——
  交易成本从"事后扣一笔钱"变成决定交易是否发生的**楔子（wedge）**，这才是它的本来角色。
- **约束的边际成本**。生态基流、健康底线各自的对偶值 = 多要一单位环境流量/健康保障
  的社会成本。这是政策简报里最有分量的数字。

⚠️ 顺带修一个相关问题：健康底线的松弛变量惩罚系数是 `−1e6`（big-M），
纯属数值占位。应改成由 `VALUE_PER_DALY` 推出的每 m³ 健康价值，
否则健康底线的对偶值没有任何经济解释。

## 3. F3 + F4 —— 健康模块没有接在水模型上，而且循环论证

现行公式：

```
dalyAvoided_i = (pop_i/1e5) × urbanCoverage_i × avoidedPer100k
avoidedPer100k = 9 + 28×climateStress + 11×healthFloor + 18×τSignal
```

**实测：四档情景下 `urbanCoverage_i` 全部恒等于 1.0000**（人口加权覆盖率 = 1.0000，
不足 100% 的节点数 = 0）。于是该项恒等于 1，公式塌缩为：

```
DALY = (32.51e6 / 1e5) × (9 + 28×climateStress + 11×healthFloor + 18×τSignal)
```

闭式复算与线上展示值**逐位吻合**：

| 情景 | 闭式复算 | 现行展示 |
|---|---|---|
| historical | 6663.7 | 6,664 |
| ssp245 | 7937.9 | 7,938 |
| dry | 8301.9 | 8,302 |
| ssp585 | 9394.1 | 9,394 |

**即：66 节点水文拓扑、LP 求解、水权交易、地图圈选，对头条健康数字的贡献为零。**
换掉整个水模型，DALY 一个数都不会变。它只是 3,251 万人口乘上一个四项多项式。

在此基础上还有两个独立的方法论问题：

**F4a 循环论证。** τ 和 healthFloor 作为**政策旋钮直接出现在健康收益函数里**。
所以"τ 从 0 升到 50%，DALY 从 5,129 升到 10,980"不是模型的**结论**，而是系数 18
被乘出来的**定义**。实际上整条关系是完美线性的：`DALY = 5129.4 + 11702.2·τ`。
这在评审中会被直接指为 assuming the conclusion。

**F4b 不是剂量—反应函数。** `9 / 28 / 11 / 18` 是评分权重，不是流行病学参数。
GBD 口径的归因需要：暴露量 → 相对危险度 RR → 人群归因分值 PAF → DALY。
现在这条链一环都没有。

**正确的因果链应该是**（政策旋钮**只能**通过配置影响健康）：

```
τ ↑ → 工业取水 ↓ → 河道流量 ↑ / 生活与生态配水 ↑ → 暴露 ↓ → PAF ↓ → DALY ↓
```

这也正是 B1 需要聂弘宇提供的东西：不是"给 9/28/11/18 找引用"，
而是**给出一条以配水量为自变量的剂量—反应关系**。这一点必须尽快同步给他，
否则他会按错误的方向查文献。

## 4. F5 —— 成本侧缺失：最容易被问倒、也最容易变成加分项

现行：`economicNpv = healthBenefit − tradingCost`，而默认情景成交量为 0，
所以 `tradingCost = 0`，于是 **NPV ≡ 健康收益，成本恒为零**。

缺失的项，以及它们各自的正确处理：

| 缺失项 | 现状 | 正确处理 |
|---|---|---|
| 工业产出损失 | 完全没有 | 见下方推导——**是 DWL 三角形，不是全价** |
| 税收收入 | 没有报告 | **是转移支付，不计入社会成本**，但必须单独展示 |
| 市场运行的行政/监测成本 | 没有 | 应作为固定成本项 |
| 贴现与年限 | 没有 | "NPV"名不副实，见下 |

### 4.1 关键推导：庇古税的社会成本是 DWL，不是被砍掉的水的全价

这是整份审计里最重要的一段。用模型自己的参数算两种口径：

| τ | 工业减少取水 Δq | 口径 A：Δq × 1.45 元/m³（**错误**） | 口径 B：Harberger DWL = ½·Δq·t（**正确**） | 税收收入（转移） |
|---|---|---|---|---|
| 24% | 5.97 亿 m³ | **8.65 亿元** | **0.29 亿元** | 4.60 亿元 |
| 50% | 12.43 亿 m³ | **18.02 亿元** | **1.26 亿元** | 8.27 亿元 |

（税率为工业取水量加权的平均健康税：τ=24% 时 0.0976 元/m³，τ=50% 时 0.2033 元/m³。）

**为什么口径 A 错**：企业面对水价上涨不会等比例减产，而是投资节水、循环利用、
改工艺。减少 11.2% 的取水，损失的**不是** 11.2% 的产出，而只是最边际那部分用水的
消费者剩余——即需求曲线下的三角形。这就是 `ε = 0.90` 这个弹性参数存在的意义：
它已经蕴含了"企业可以替代"。用全价计损失等于既承认弹性、又假装没有弹性，自相矛盾。

**净社会收益对照**：

| τ | 健康收益 | 口径 A 净值 | **口径 B 净值（正确）** |
|---|---|---|---|
| 0% | 6.41 亿 | 6.41 亿 | 6.41 亿 |
| 24% | 9.92 亿 | **+1.27 亿** | **+9.63 亿** |
| 50% | 13.73 亿 | **−4.30 亿** | **+12.46 亿** |

**这就是必须马上做这件事的理由**：现在展示的 +9.92 亿之所以接近正确答案（+9.63 亿），
纯粹是因为**成本恰好很小**，而不是因为算对了。一旦评委问"工业的损失呢"，
按直觉给出的答案是 8.65 亿，净收益立刻从 9.92 亿掉到 1.27 亿，τ=50% 还会变负——
**头条数字当场崩掉。** 把 DWL 推导补上，这个致命提问就变成全场最强的一个回答。

### 4.2 税收收入 4.60 亿元/年 —— 现在完全没报告的一张牌

这笔钱是转移支付，不算社会成本，但它是**真实的财政工具**：
可定向用于供水管网改造、农村饮水安全、WASH 基础设施——
从而**回流到健康产出上，形成闭环**。这对政策简报和路演都是极强的素材，
目前一个字都没提。

### 4.3 "NPV" 名不副实

现在是**单年**的收益减成本，既无年限也无贴现，叫 NPV 是错的。两条路：

- **保守**：改名为「年度净社会收益（annual net social benefit）」，成本最低，今天就能改。
- **完整**：设定年限（如 20 年）+ 贴现率，做真 NPV。贴现率有官方可引用值——
  国家发改委《建设项目经济评价方法与参数（第三版）》社会折现率 **8%**。

建议先做保守版改名（避免口径错误），完整版视时间再说。

## 5. F6 —— 参数档案：每个常量该由什么决定

补引用之前必须先问「这个数在经济学上是什么」。有几个常量的问题是**定义不清**，
不是缺引用。

| 常量 | 当前值 | 经济学含义 | 取值应由什么决定 | 状态 |
|---|---|---|---|---|
| `DEFAULT_SECTOR_VALUE` | urban 3.2 / eco 2.4 / ind 1.45 / agri 1.15 元/m³ | 各部门用水的**边际价值产品 MVP** | 武汉分部门水价表 + 生产函数/CGE 影子价格估计；农业用 作物预算模型 | 可查证 |
| `DEFAULT_COMPLIANCE_COST` | 0.28 / 0.08 / 0.18 / 0.52 | **定义不明** | ⚠️ 先定义：是取水许可费、水资源税，还是排污费？《环境保护税法》有明文税率。**另外代码里乘了 0.01，实际几乎不起作用——先确认是不是 bug** | 定义待定 |
| `HEALTH_LOSS_COEFF.industry` | 0.52 | 工业每 m³ 取水的边际健康损害 | 应由损害函数导出。⚠️ **当前一个数同时充当税基和需求收缩系数，是两个不同的经济角色，应拆开** | 结构问题 |
| 需求弹性 `ε` | 0.90 | 工业用水的**价格弹性** | 有真实文献：中国工业用水价格弹性估计多在 **0.3–1.0**，0.90 处于高端 | 可查证，需区间 |
| `INDUSTRY_DEMAND_FLOOR_FRACTION` | 0.40 | 技术上不可再压缩的工艺用水下限 | 湖北省用水定额标准（DB42/T）分行业限值 | 可查证 |
| `CLIMATE_AVAILABILITY` | 0.86 / 0.82 / 0.70 | SSP 情景下的径流变化 | CMIP6 长江流域径流预估 | 可查证 |
| `VALUE_PER_DALY` | ¥125,000 | 统计生命年价值 VSLY | 需明确声明惯例：WHO-CHOICE 的 1–3× 人均 GDP。2022 年中国人均 GDP ≈ ¥85,700，故 ¥125,000 ≈ **1.46×**，可辩护，但**必须报区间 ¥86k–¥257k** | 可查证，需区间 |
| `DISEASE_CASE_DALY` | 0.18 | 每病例 DALY | 完全取决于是哪种疾病，需 GBD 分病种 | 依赖 F4 定链 |
| `tradingCost` | 10% | 交易摩擦 | ⚠️ 量纲错：代码是 `成交量 × 0.10` = 元，隐含 **0.10 元/m³**，不是百分比。UI 标成 % 会误导。应按中国水权交易所实际费率标定 | 量纲待改 |
| `avoidedPer100k` 系数 | 9 / 28 / 11 / 18 | 无 | **不应补引用，应整体删除**并换成剂量—反应（见 F4） | 待重构 |
| 健康底线罚项 big-M | 1e6 | 无 | 应由 `VALUE_PER_DALY` 折算成每 m³ 健康价值 | 待重构 |
| `riverRetentionValueScale` | 5.4 | 河道内流量的价值 | 生态系统服务价值评估文献 | 可查证 |

**分类小结**：12 个里只有 6 个是「查文献就能解决」；其余 6 个是定义不清、量纲错误
或结构问题——**必须先修，修完才谈引用**。

## 6. 不确定性区间（兑现表单 Q26 的承诺）

Q26 明确承诺「报告不确定性区间而非点估计」，目前一个区间都没有。

好消息是成本极低：单次 LP 求解 35–405 ms，跑 1,000 次蒙特卡洛离线几分钟即可。

方案：

1. 给每个参数配分布（优先用文献区间的三角分布/均匀分布，而非拍脑袋的正态）；
2. 1,000 次抽样求解，报告 DALY、净社会收益、成交量的 **P5 / P50 / P95**；
3. 出一张**龙卷风图**，显示哪个参数主导了不确定性。

第 3 点本身就是强有力的成果：几乎可以肯定 `VALUE_PER_DALY` 和剂量—反应系数会主导，
而这恰好证明「B1 健康参数校准是关键路径」这一判断——用我们自己的模型证明的。
这在 50 进 25 的桌面评审里是明确的差异化项。
